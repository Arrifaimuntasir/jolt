# JOLT Website UI - Vercel Deployment

Huu ni muundo kamili na wa haraka wa UI ya tovuti ya JOLT uliotengenezwa tayari kwa ku-deploy Vercel kwa sekunde chache.

## Namna ya Ku-deploy Vercel:

### Njia ya 1: Vercel CLI (Haraka Zaidi - Sekunde 30)
Kwenye Terminal (ndani ya folda hii `jolt_web_preview`):
```bash
npx vercel
```
1. Itakuuliza: `Set up and deploy?` -> andika `y` kisha bonyeza Enter.
2. Fuata maelekezo madogo ya Vercel (chagua akaunti yako).
3. Ndani ya sekunde chache utapata link yako ya bure kama: `https://jolt-tanzania.vercel.app`.

---

### Njia ya 2: Kupitia Vercel Dashboard (Bila Kufungua Terminal)
1. Ingia kwenye akaunti yako ya [vercel.com](https://vercel.com).
2. Bonyeza kitufe cha **"Add New..."** -> **"Project"**.
3. Pakia (Upload / Import) folda hii ya `jolt_web_preview` moja kwa moja au kuiweka kwenye GitHub kisha ku-import.
4. Bonyeza **"Deploy"**.
5. Tovuti yako itakuwa hewani papo hapo!
